## Atividade 1 – Teoria dos Conjuntos

**Arquivo:**

`P1/atividade_01_conjuntos/conjuntos.py`

### Como executar

Execute o arquivo `conjuntos.py`.

O programa solicitará ao usuário os elementos dos conjuntos A e B.

### Exemplo de entrada

```text
Conjunto A: 1 2 3 4
Conjunto B: 3 4 5 6
```

### O programa apresenta

- união;
- interseção;
- diferenças A - B e B - A;
- cardinalidades;
- conjunto das partes;
- cardinalidade dos conjuntos das partes;
- exemplo de partição;
- produto cartesiano;
- verificação de inclusão entre os conjuntos.

## Atividade 2 – Divisibilidade, MDC e MMC

**Arquivo:**

`P1/atividade_02_divisibilidade/divisibilidade.py`

### Como executar

Execute o arquivo `divisibilidade.py`.

O programa solicitará dois números inteiros positivos.

### Exemplo de entrada

```text
Primeiro número: 48
Segundo número: 18
```

### O programa apresenta

- divisão inteira (DIV);
- resto da divisão (MOD);
- passo a passo do Algoritmo de Euclides;
- MDC;
- MMC.

O MDC é calculado utilizando o Algoritmo de Euclides, sem o uso de funções prontas que forneçam diretamente o resultado.
